# Sabor&Arte — Guimarães

Site da padaria e pastelaria **Sabor&Arte** (Rua da Estrada Nacional 105, nº 1699, loja 2, 4835-164 Guimarães).
Pão quente · Pastelaria · Pizzaria · Gelataria — fabrico próprio.

Site estático (HTML + CSS + JS, sem build).

## Ver localmente

```bash
python -m http.server 5173
```

## Editar morada, telefone e horário

Tudo está no bloco `CONFIG` no início de `script.js`.
